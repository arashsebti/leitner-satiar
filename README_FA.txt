لایتنر ساتیار — نسخه ۴ (نهایی آزمایشی وب)

نمودار پیشرفت هر کارت در بخش «کارت‌ها» > «نمودار پیشرفت» قابل مشاهده است.
تاریخچه از نسخه ۴ به بعد ثبت می‌شود؛ پاسخ‌های قدیمی تنها به شکل تعداد کل و تعداد صحیح موجودند.
فایل JSON شامل history با زمان ISO و مقدار ok برای هر پاسخ است و در دستگاه دیگر قابل بازیابی است.

قبل از ارتقا از نسخه ۳ فایل JSON پشتیبان بگیرید. برای اجرا در ویندوز، در پوشه برنامه CMD باز کنید:
py -m http.server 8000
سپس http://localhost:8000 را در Chrome باز کنید. Ctrl+Shift+R برای نوسازی.
اگر Service Worker قدیمی فایل‌ها را نگه داشت، از Chrome DevTools > Application > Service Workers گزینه Unregister و سپس Hard Reload را بزنید.

نکته: انتقال با JSON دستی است؛ همگام‌سازی خودکار وجود ندارد. این نسخه مرور آزاد است، نه مرور فاصله‌دار تقویمی.
