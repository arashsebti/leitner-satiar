لایتنر ساتیار V5 - بسته آماده نصب PWA

۱. فایل‌های داخل پوشه leitner_satiar را در یک میزبان HTTPS ثابت (مثلاً GitHub Pages یا Netlify) منتشر کنید.
۲. آدرس HTTPS را در Chrome تبلت باز کنید.
۳. از منوی سه‌نقطه Chrome گزینه Install app یا Add to Home screen را انتخاب کنید.
۴. برنامه را یک بار آنلاین کامل باز کنید، سپس اینترنت را قطع و عملکرد آفلاین را آزمایش کنید.
۵. برای انتقال کارت‌ها، در نسخه قدیمی بخش پشتیبان خروجی JSON بگیرید و در نسخه جدید وارد کنید.

توجه: اطلاعات کارت‌ها در localStorage همان مرورگر/آدرس نگهداری می‌شود. از فایل JSON به‌طور منظم نسخه پشتیبان بگیرید.
